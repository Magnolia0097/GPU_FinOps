# ADR-0004: 가격은 실측 API에서만 가져온다

- **상태**: 채택
- **일자**: 2026-09-14

## 배경

두 트레이스 모두 **사용량은 있고 가격은 없다.**
비용을 계산하려면 가격을 어딘가에서 가져와야 한다.

그리고 다음 질문은 면접에서 반드시 나온다.

> "그 비용 숫자, 어디서 나온 건가요? 직접 지어내신 건가요?"

이 질문에 답하지 못하면 프로젝트 전체의 신뢰가 무너진다.
비용 프로젝트에서 가격의 출처는 **부수적 디테일이 아니라 핵심**이다.

## 결정

**가격은 코드나 문서에 하드코딩하지 않는다.**

| 항목 | 출처 | 성격 |
|---|---|---|
| 온디맨드 · 예약 정가 | AWS Price List Bulk API | 실측, 인증 불필요 |
| 스팟 가격 이력 | AWS `describe_spot_price_history` | **실측 시계열**, 90일 |
| 국내 CSP 요금 | 공개 요금표 수동 수집 | 출처 URL · 수집일 필수 기록 |
| 온프레미스 TCO | `config/tco.yaml` | **가정값. 전부 민감도 분석 대상** |

수집한 모든 가격은 **수집 시각과 함께** 적재한다.

## 근거

1. **출처를 댈 수 있어야 한다.**
   "AWS Price List API에서 매일 수집합니다"는 검증 가능한 답이다.
   "일반적으로 시간당 3달러 정도라고 알려져 있어서요"는 답이 아니다.

2. **스팟 가격은 실측 시계열이라 이중으로 쓰인다.**
   비용 계산의 입력값이면서, **L2 예측의 두 번째 예측 대상**이다.
   트레이스가 과거 데이터라 예측 검증이 제한적인데, 스팟 가격이 그 공백을 메운다.

3. **API로 얻을 수 없는 것만 가정한다.**
   온프레미스 TCO는 공개 API가 없다. 그래서 이 영역만 가정이고,
   **가정이라는 사실을 설정 파일 구조로 강제 노출한다** (`confidence` 필드).

4. **절대값을 주장하지 않는 설계와 맞물린다.**
   가격 수집 시점과 트레이스 시점이 다르다는 한계는 해소 불가능하다.
   따라서 산출물을 "이 클러스터의 비용은 N억원"이 아니라
   **"손익분기 가동률은 X%"** 라는 상대 지표로 정의했다 (ADR-0001).
   이 정의 하에서는 시점 불일치가 결론을 훼손하지 않는다.

## 검토한 대안

| 대안 | 장점 | 단점 | 기각 사유 |
|---|---|---|---|
| 가격 상수를 코드에 하드코딩 | 가장 빠름 | 출처 불명, 갱신 불가, 면접 방어 불가 | **프로젝트 신뢰도의 근간을 포기하는 선택** |
| 블로그·기사에서 가격 인용 | 수집 불필요 | 2차 출처, 시점 불명, 조건(리전·약정) 불명 | 검증 불가 |
| 가격도 트레이스 시점(2020)으로 재구성 | 시점 일관성 확보 | 2020년 가격 이력을 공개 API로 얻을 수 없음 | 실현 불가 |
| CSP 요금 협상가 추정 | 현실적 | 비공개 정보, 근거 제시 불가 | 검증 불가 |
| 온프레미스 TCO도 외부 리포트 인용 | 권위 있어 보임 | 조건이 다른 환경의 수치를 가져오는 것 | 가정을 숨기는 형태가 됨. **가정은 드러내야 한다** |

## 결과

**얻는 것**
- 가격 출처에 대한 완전한 방어
- 스팟 가격이라는 추가 예측 대상 확보
- 가정과 실측이 구조적으로 분리됨

**포기하는 것**
- AWS 자격증명 설정 필요 (스팟 이력 조회). 단, 조회 자체는 무과금
- 가격 수집 DAG 구현 공수
- 시점 불일치는 해소되지 않음 — 산출물 정의로 우회할 뿐

**강제 규칙**
- 코드에 가격 리터럴이 나타나면 리뷰에서 반려
- `config/tco.yaml` 의 모든 값에 `source` 와 `confidence` 를 붙인다
- `confidence: low` 인 값은 전부 민감도 분석에 포함한다
- 최종 리포트는 단일 숫자가 아니라 **범위**로 제시한다

## 재검토 조건

- AWS 자격증명 확보가 불가능하면 Price List API(무인증)만 사용하고
  스팟 축을 범위에서 제외한다. 그 경우 L2의 예측 대상이 하나 줄어든다.
